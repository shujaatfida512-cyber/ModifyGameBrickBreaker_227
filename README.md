# Neon Brick Breaker Game

## Project Description
This project is a modified version of the original Brick Breaker Game developed using Python and Pygame.

The game has been improved with new visual features and additional functionality to provide a better gaming experience.

## Features and Modifications

1. **Modern Colors and Title** – Updated game colors and window title.
2. **Improved Graphics** – Redesigned the paddle and bricks with rounded borders.
3. **Pause and Resume** – Press `P` to pause or resume the game.
4. **Game Over and Restart** – Press `R` to restart after Game Over or `ESC` to exit.
5. **High Score System** – Saves the highest score in `highscore.txt`.
6. **Game Instructions** – Displays keyboard controls on the screen.
7. **Improved Brick Layout** – Adjusted brick positions to make room for instructions.

## Technologies Used
- Python
- Pygame
- Git and GitHub

## How to Run

1. Install Python.
2. Install Pygame:
   ```bash
   pip install pygame
   ```
3. Run the game:
   ```bash
   python Main.py
   ```

## Controls

| Key | Action |
|---|---|
| LEFT Arrow | Move paddle left |
| RIGHT Arrow | Move paddle right |
| P | Pause / Resume |
| R | Restart after Game Over |
| ESC | Exit from Game Over screen |
